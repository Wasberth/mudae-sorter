# Mudae Harem Sorter

This is a open-source page to help you sort your mudae harem / collection in a visual way.

## Features

Import or update your harem with the command provided to include kakera value and image link.
List of unsorted vs sorted characters to have visual progress indication
Buckets to further help sort characters easier based on manual categories
Discord command export for nitro and non-nitro users

## Bug reporting / Collaboration

Feel free to fork the repo and make a pull request, I'll try to check them out and merge them for any bug you find or new features you may want to include.
You can also report any bug you find in the issues and I'll do my best to fix them.
